# Определитель позиций для Google Search Console

Скрипт выполняет автоматический сбор статистики о позициях сайта в Google Search Console по списку ключевых слов и выгружает результаты в Excel-файл.

## 📦 Установка

1. **Клонируйте репозиторий** или скачайте скрипт.
2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Получите ключ доступа** к Google Search Console API:
   - Создайте проект в [Google Cloud Console](https://console.cloud.google.com/).
   - Включите **Search Console API**.
   - Создайте сервисный аккаунт и скачайте JSON-ключ.
4. **Переименуйте скачанный JSON-файл** в `gsc-key.json` и поместите его в папку со скриптом.
5. **Дайте доступ скрипту к вашему сайту в Google Search Console:**
   - Откройте скачанный JSON-файл в Блокноте и скопируйте значение поля `"client_email"` (это будет что-то вроде `имя-сервисного-аккаунта@ваш-проект.iam.gserviceaccount.com`).
   - Перейдите в [Google Search Console](https://search.google.com/search-console) и выберите ваш сайт.
   - В левом меню нажмите **«Настройки» (Settings)**, затем — **«Пользователи и разрешения» (Users and permissions)**.
   - Нажмите **«Добавить пользователя» (Add user)**.
   - Вставьте скопированный email из JSON-файла (`client_email`).
   - Выберите разрешение **«Только для чтения» (Read)**.
   - Нажмите **«Добавить» (Add)**.

## 🚀 Запуск

1. В файле keywords.txt запишите каждое ключевое слово с новой строки (пример ниже).

2. Запустите скрипт и следуйте инструкциям:
   ```bash
   python rank_tracker.py
   ```
3. Введите URL вашего сайта (например, `https://example.com/`).
4. Укажите количество дней для анализа (например, `28`).

**Пример содержимого файла `keywords.txt`:**
```
Ключевое слово 1
Ключевое слово 2
Ключевое слово 3
```

## 📊 Результат работы

После успешного выполнения в папке со скриптом появится Excel-файл с названием `positions_YYYYMMDD_HHMMSS.xlsx`, который содержит:

| Колонка | Описание |
|---------|----------|
| **Key Word** | Ключевое слово |
| **Position** | Средняя позиция в поисковой выдаче Google (если сайт не попал в топ-10, будет указано "Not in TOP-10") |
| **Clicks** | Количество переходов на сайт из результатов поиска |
| **Impressions** | Количество показов сайта в результатах поиска |

## ⚙️ Требования к системе

- Python 3.8 или выше
- Активный сайт, добавленный в Google Search Console
- Сервисный аккаунт с доступом к Search Console API
